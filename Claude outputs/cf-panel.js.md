# content/cf-panel.js

The folders flyout panel: header actions (analytics, organizer, setup toggle, close), the setup actions (Ask Claude to Organize, Apply Claude's Response), the account filter and the folder list with per-folder export.

The panel's left edge is measured from the sidebar element holding the Folders row, so it sits flush in both sidebar widths.

The Import Shared Chats button added in 1.3.0 was removed in 1.3.5. Importing moved to a button beside the shared chats on project pages (content/cf-project-import.js).

Cowork rows carry a "Cowork" label in the `.folder-chat-org` style.
