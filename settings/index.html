Folders panel

The account dropdown in the Folders panel changes the view for each login. Saving a choice here resets those changes.

Automatic sync

Automatic sync is on every 1 hour until it is changed here. The sync runs in an open claude.ai tab with a writable data folder. A turn with no claude.ai tab open is skipped. A notice appears on claude.ai only after an automatic sync with new, exported or updated chats.

Settings file

Clicking Export settings saves the choices of these settings, the Folders panel and the organizer as a JSON file. Clicking Import settings reads such a file and replaces those choices.

Folder lists for Claude

Clicking Export chat list opens the organizer, copies the chat list for Claude to organize and downloads it as a file. Clicking Import organized folders opens the organizer with the box for Claude's organized JSON.

Import from another account

Claude Folders

Claude Folders is a browser extension that sorts your claude.ai chats and Cowork sessions into folders, saves each one as a markdown file in a folder on your computer, and adds an organizer page, content search and an offline library.

The folders, the exported files and the settings are stored on your computer. The extension has no account, no telemetry and no server of its own.
